# bspwmctl scripts

> 🚧 **Coming soon.** This repository is not open for submissions yet.

A community collection of scripts for bspwm desktops set up with [bspwmctl](https://github.com/bspwmctl/bspwmctl).

## What will be here

Small, useful scripts to extend your desktop, for example:

- 🪟 Window helpers (scratchpads, swallowing, smart resize...)
- 📊 Polybar modules (weather, updates, VPN, music...)
- 🚀 Rofi menus (power menu, wifi, clipboard, emoji picker...)
- 🛠️ Everyday utilities for a bspwm workflow

Each script will come with a short description, its dependencies and how to use it.

## Share your script

Once the repository is ready, you will be able to submit your scripts with a pull request. Since scripts run on your machine, **every script will be reviewed** before being added.

Until then, you can follow the progress in the [bspwmctl repository](https://github.com/bspwmctl/bspwmctl) or [open an issue](https://github.com/bspwmctl/bspwmctl/issues) with your ideas.
